# C扫指针工具

**Android ARM64 · 版本 1.2.2 · 作者：jx小新**

C扫指针工具是一款原生 Android 指针链扫描工具，提供本机网页工作台、命令行和终端菜单，适合扫描、保存并复查进程中的指针链。

## 功能亮点

- **多线程内存采集**：普通读取器默认按设备核心数自动选择工作线程，最多 4 个；CLI 可通过 `--threads` 调整，范围为 1–32。Paradise 读取器按协议串行工作。实际速度取决于设备、读取方式和目标进程。
- **共享链图结果**：重复的链路后缀可以共用存储节点，减少重复保存；比较和过滤时可直接处理图结构。
- **扫描后继续筛选**：保存结果后可与其他扫描结果比较，或根据目标进程当前地址过滤，逐步缩小结果范围。
- **多种使用方式**：网页工作台可查看进程与模块、提交任务和管理结果；需要时也可用命令行或终端菜单操作。
- **本机文件读写**：结果保存在本地，支持二进制结果与文本的导入、导出；网页工作台通过设备本机地址访问，不依赖云端服务或联网加载页面。

## 运行

在 Android 上将 `bin/cscan-android-arm64` 放到允许执行的位置，然后运行：

```sh
chmod +x cscan-android-arm64
./cscan-android-arm64
```

在同一设备的浏览器打开 `http://127.0.0.1:18760`。读取其他应用通常需要 Android 原生 Root 权限；工具不会自行提权或安装驱动。

扫描结果保存在本地的 `cscan-data/` 目录。启动脚本会将结果保存在 `data/`；这些数据目录不会提交到 Git。

## 从源码构建

设置 `ANDROID_NDK_HOME` 指向已安装的 Android NDK 后运行：

```sh
bash scripts/build-android.sh
```
